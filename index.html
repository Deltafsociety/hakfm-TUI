Terminal Radio Receiver.

Curated hacker streams, ambient frequencies, and live web search in your terminal.

$curl -fsSL https://raw.githubusercontent.com/Deltafsociety/hakfm-TUI/main/install.sh | bash

One-liner installer for Linux & macOS · Powered by headless mpv

Preset Stations

Direct SomaFM streams including DEF CON Radio, Drone Zone, Groove Salad, and Deep Space One.

Live Web Search

Query and stream thousands of internet-radio.com stations live inside the TUI via i.

Custom Streams

Add your own streams (.mp3, .pls, .m3u, Icecast). Automatically saved in your config.

Vim & Arrow Keys

Full keyboard control with standard arrow navigation or classic hjkl bindings.

Favorites & Filters

Star stations with s, view favorites with f, or search locally with /.

Lightweight & Fast

Written in Rust with Ratatui and backed by mpv. Minimal CPU and memory footprint.
